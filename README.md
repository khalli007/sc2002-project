# 🎓 SC2002 Project – Internship Management System

This project is a Java-based application developed for **SC2002 Object-Oriented Design & Programming** at NTU.  
It simulates a **Student Internship Management System**, allowing different user roles (Students, Company Representatives, and Staff) to interact within a structured interface.

---

## 🧩 Project Overview

The system provides functionality for:
- Managing internship postings and applications  
- Tracking student and company data  
- Handling approvals, withdrawals, and allocations  

---
## ⚙️ Compilation Instructions

Open a terminal in the project root folder and run:
```bash
javac -d bin src/controller/*.java src/model/*.java src/view/*.java

```
After compilation, run the main class with:
```bash
java -cp bin view.MainApp

```
